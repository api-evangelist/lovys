# Lovys

> Lovys is a European digital neo-insurance provider offering flexible, subscription-based cover for home (habitation), smartphone, and pet insurance. Lovys exposes a Partner API (the "Lovys Partner API") that lets resellers and platforms embed insurance products — creating and managing real-time quotes, retrieving plans/pricing/coverage, capturing customer data, purchasing and activating policies, and handling the policy lifecycle, updates, and renewals. The API is fronted by Azure API Management with OAuth2 (Microsoft Entra ID / Azure AD B2C) authentication.
